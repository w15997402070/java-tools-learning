# Day 36: Apache Commons Compress — 多种压缩格式统一处理库

## 1. 工具简介

**Apache Commons Compress** 是 Apache 基金会维护的 Java 压缩/解压库，提供统一的 API 处理市面上几乎所有主流压缩格式：

- **归档格式**：ZIP、TAR、7Z、AR、CPIO、DUMP、JAR
- **压缩格式**：GZIP、BZIP2、XZ、LZMA、Pack200、DEFLATE、Z、LZ4、Snappy、Zstd
- **特殊能力**：自动格式检测、内存中操作、流式大文件处理、CRC 校验

**GitHub**: https://github.com/apache/commons-compress  
**官方文档**: https://commons.apache.org/proper/commons-compress/  
**Maven Central**: https://mvnrepository.com/artifact/org.apache.commons/commons-compress  
**星标**: 700+（Apache 官方项目，Maven Central 月下载量极高）  
**版本**: 1.26.0（Java 8 兼容；1.27+ 建议 Java 11+）

### 同类工具对比

| 工具 | 支持格式 | 优势 | 劣势 |
|------|----------|------|------|
| **Commons Compress** | ZIP/TAR/7Z/GZIP/BZIP2/XZ/LZ4/Zstd 等 | 统一 API、自动检测、Apache 官方 | 7Z 写操作不支持加密 |
| **JDK ZIP** | ZIP/GZIP/JAR | 无需依赖 | 功能有限、中文文件名乱码、无 TAR/7Z |
| **zip4j** | ZIP | 支持 AES-256 加密 | 仅 ZIP 格式 |
| **Apache Ant Compress** | ZIP/TAR/GZIP | Ant 任务集成 | 已停止维护 |
| **XZ for Java** | XZ/LZMA | XZ 算法官方实现 | 仅 XZ 格式 |

## 3. 核心功能速查

### 3.1 ZIP 操作

```java
// 创建 ZIP
ZipArchiveOutputStream zos = new ZipArchiveOutputStream(new FileOutputStream("out.zip"));
zos.setEncoding("UTF-8"); // 解决中文文件名乱码

ZipArchiveEntry entry = new ZipArchiveEntry("file.txt");
entry.setSize(data.length);
zos.putArchiveEntry(entry);
zos.write(data);
zos.closeArchiveEntry();
zos.close();

// 读取 ZIP
ZipArchiveInputStream zis = new ZipArchiveInputStream(new FileInputStream("in.zip"), "UTF-8");
ZipArchiveEntry entry;
while ((entry = zis.getNextZipEntry()) != null) {
    byte[] buf = new byte[(int) entry.getSize()];
    IOUtils.readFully(zis, buf);
}
zis.close();
```

### 3.2 GZIP 操作

```java
// 带元数据的 GZIP 压缩
GzipParameters params = new GzipParameters();
params.setFilename("original.txt");
params.setComment("Generated by app");
params.setCompressionLevel(6); // 1-9

GzipCompressorOutputStream gzos = new GzipCompressorOutputStream(
    new FileOutputStream("out.gz"), params);
IOUtils.copy(new FileInputStream("in.txt"), gzos);
gzos.close();

// GZIP 解压并读取元数据
GzipCompressorInputStream gzis = new GzipCompressorInputStream(
    new FileInputStream("in.gz"));
String filename = gzis.getMetaData().getFilename();
IOUtils.copy(gzis, new FileOutputStream("out.txt"));
gzis.close();
```

### 3.3 TAR 操作

```java
// 创建 TAR
TarArchiveOutputStream tos = new TarArchiveOutputStream(new FileOutputStream("out.tar"));
tos.setLongFileMode(TarArchiveOutputStream.LONGFILE_GNU); // 长文件名支持

TarArchiveEntry entry = new TarArchiveEntry("file.txt");
entry.setSize(data.length);
entry.setMode(0644); // Unix 权限
tos.putArchiveEntry(entry);
tos.write(data);
tos.closeArchiveEntry();
tos.close();
```

### 3.4 7Z 操作（随机访问）

```java
// 创建 7Z
SevenZOutputFile szOut = new SevenZOutputFile(new File("out.7z"));
SevenZArchiveEntry entry = szOut.createArchiveEntry(new File("file.txt"), "file.txt");
entry.setContentCompression(SevenZArchiveEntry.CompressionMethod.LZMA2);
szOut.putArchiveEntry(entry);
szOut.write(data);
szOut.closeArchiveEntry();
szOut.close();

// 随机访问读取（不需要按顺序）
SevenZFile szIn = new SevenZFile(new File("in.7z"));
for (SevenZArchiveEntry e : szIn.getEntries()) {
    if ("target.txt".equals(e.getName())) {
        byte[] buf = new byte[(int) e.getSize()];
        szIn.read(buf);
    }
}
szIn.close();
```

### 3.5 自动格式检测

```java
// 自动检测压缩格式并解压
CompressorInputStream cis = new CompressorStreamFactory()
    .createCompressorInputStream(new FileInputStream("file.bz2"));
IOUtils.copy(cis, new FileOutputStream("out.txt"));
cis.close();

// 自动检测归档格式
ArchiveInputStream ais = new ArchiveStreamFactory()
    .createArchiveInputStream(new FileInputStream("file.tar"));
```

### 3.6 内存中操作

```java
// 内存中创建/读取 7Z，无需磁盘文件
```

### 4.2 通用压缩服务

```java
@Service
public class CompressService {

    private static final int BUFFER_SIZE = 64 * 1024;

    /**
     * 将目录压缩为 ZIP 字节数组
     */
    public byte[] zipDirectory(Path sourceDir) throws IOException {
        try (ByteArrayOutputStream baos = new ByteArrayOutputStream();
             ZipArchiveOutputStream zos = new ZipArchiveOutputStream(baos)) {
            zos.setEncoding("UTF-8");
            Files.walkFileTree(sourceDir, new SimpleFileVisitor<Path>() {
                @Override
                public FileVisitResult visitFile(Path file, BasicFileAttributes attrs) throws IOException {
                    String entryName = sourceDir.relativize(file).toString().replace("\\", "/");
                    ZipArchiveEntry entry = new ZipArchiveEntry(file.toFile(), entryName);
                    zos.putArchiveEntry(entry);
                    Files.copy(file, zos);
                    zos.closeArchiveEntry();
                    return FileVisitResult.CONTINUE;
                }
            });
            zos.finish();
            return baos.toByteArray();
        }
    }

    /**
     * 解压 ZIP 到指定目录
     */
    public void unzip(InputStream input, Path targetDir) throws IOException {
        try (ZipArchiveInputStream zis = new ZipArchiveInputStream(input, "UTF-8", true, true)) {
            ZipArchiveEntry entry;
            while ((entry = zis.getNextZipEntry()) != null) {
                Path outPath = targetDir.resolve(entry.getName()).normalize();
                // 防止 Zip Slip 漏洞
                if (!outPath.startsWith(targetDir)) {
                    throw new IOException("非法条目路径: " + entry.getName());
                }
                if (entry.isDirectory()) {
                    Files.createDirectories(outPath);
                } else {
                    Files.createDirectories(outPath.getParent());
                    Files.copy(zis, outPath, StandardCopyOption.REPLACE_EXISTING);
                }
            }
        }
    }

    /**
     * 自动检测格式并解压
     */
    public void autoExtract(InputStream input, String filename, Path targetDir) throws Exception {
        String lower = filename.toLowerCase();
        BufferedInputStream bis = new BufferedInputStream(input);

        if (lower.endsWith(".zip") || lower.endsWith(".jar")) {
            unzip(bis, targetDir);
        } else if (lower.endsWith(".tar")) {
            extractTar(bis, targetDir);
        } else if (lower.endsWith(".gz") || lower.endsWith(".gzip")) {
            decompressGzip(bis, targetDir.resolve(filename.replaceAll("\\.(gz|gzip)$", "")));
        } else {
            // 尝试自动检测
            try {
                ArchiveInputStream ais = new ArchiveStreamFactory().createArchiveInputStream(bis);
                extractArchive(ais, targetDir);
            } catch (ArchiveException e) {
                CompressorInputStream cis = new CompressorStreamFactory().createCompressorInputStream(bis);
                Files.copy(cis, targetDir.resolve(filename + ".out"));
            }
        }
    }
}
```

### 4.3 Controller 层示例

```java
@RestController
@RequestMapping("/api/compress")
public class CompressController {

    @Autowired
    private CompressService compressService;

    @PostMapping("/zip/download")
    public ResponseEntity<byte[]> downloadZippedDirectory(@RequestParam String dirPath) throws IOException {
        byte[] zipBytes = compressService.zipDirectory(Paths.get(dirPath));
        return ResponseEntity.ok()
            .header(HttpHeaders.CONTENT_DISPOSITION, "attachment; filename=\"archive.zip\"")
            .contentType(MediaType.APPLICATION_OCTET_STREAM)
            .body(zipBytes);
    }

    @PostMapping("/unzip")
    public ResponseEntity<String> uploadAndUnzip(@RequestParam("file") MultipartFile file,
                                                  @RequestParam String targetDir) throws Exception {
        Path target = Paths.get(targetDir);
        Files.createDirectories(target);
        compressService.autoExtract(file.getInputStream(), file.getOriginalFilename(), target);
        return ResponseEntity.ok("解压完成");
    }
}
```

## 5. 注意事项

### 5.1 Bug 风险

| 问题 | 说明 | 规避方案 |
|------|------|----------|
| **Zip Slip 漏洞** | 恶意 ZIP 包含 `../../etc/passwd` 路径，可覆盖系统文件 | 解压时校验 `outPath.startsWith(targetDir)` |
| **Zip Bomb / 压缩炸弹** | 极高压缩比文件（如 42.zip）解压后耗尽磁盘/内存 | 限制解压后总大小、设置最大条目数、使用流式处理 |
| **中文文件名乱码** | JDK 原生 ZIP 使用 CP437/UTF-8 混用导致中文乱码 | 显式设置 `ZipArchiveOutputStream.setEncoding("UTF-8")` |
| **TAR 长文件名截断** | 传统 TAR 限制 100 字符文件名 | 使用 `setLongFileMode(LONGFILE_GNU)` 启用 GNU 扩展 |
| **7Z 加密限制** | Commons Compress 不支持创建带密码的 7Z | 需要加密时使用 zip4j 或调用 7-Zip 命令行 |
| **资源泄漏** | 忘记 close 导致文件句柄泄漏 | 始终使用 try-with-resources |

### 5.2 性能问题

| 场景 | 建议 |
|------|------|
| **大文件（>100MB）** | 使用流式 API，设置 64KB+ 缓冲区，避免 `Files.readAllBytes()` |
| **高并发压缩** | 每个线程使用独立的流实例，避免共享 `ArchiveStreamFactory` |
| **压缩率 vs 速度** | GZIP(快) < ZIP(中) < BZIP2(慢/高压缩) < XZ(最慢/最高压缩) |
| **7Z 随机访问** | 利用 `SevenZFile` 的随机访问能力，避免遍历整个归档 |
| **内存限制** | 使用 `SeekableInMemoryByteChannel` 仅在必要时，大文件应写磁盘 |

### 5.3 使用限制

- **Java 版本**：1.26.0 要求 Java 8+；1.27+ 建议 Java 11+
- **7Z 加密**：读取支持 AES-256 加密，但写入不支持加密
- **ZIP64 扩展**：默认启用，支持 >4GB 文件和 >65535 条目
- **符号链接**：TAR 支持符号链接，ZIP 支持有限
- **文件时间精度**：某些格式（如 ZIP）时间精度为 2 秒
